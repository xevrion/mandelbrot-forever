z = z² + c · an interactive fractal

mandelbrot forever

a shape with an infinitely detailed edge. zoom in anywhere on the boundary and there is always more. all of it comes from one line of math, repeated.

wait, what is this

this is the mandelbrot set, probably the most famous picture in all of math. the black shape in the middle is the set itself, and the colors around it show how quickly each point outside it "escapes". the wild part is the edge: no matter how far you zoom in, it never gets smooth. there are tiny copies of the whole shape hiding inside its own edge, forever. genuinely infinite detail from a formula you could write on a napkin.

and here's the thing that gets people: the formula is z = z2 + c. that's it. pick a point c, start z at zero, and keep squaring and adding. if z stays small forever, the point is in the set (black). if it blows up to infinity, it's outside, and the color tells you how many steps it took to blow up. every single pixel on screen is that one calculation, done hundreds of times.

how to explore: click anywhere to glide into that spot. scroll to zoom. drag to pan. hover and watch the little window in the corner, that's the julia set for the point under your cursor, a whole second fractal that changes as you move. try the bookmarked spots for the famous places. the url updates as you go, so copy it to share anywhere you find.

what you're seeing: every pixel is a point c in the complex plane (left-right is the real part, up-down is the imaginary part). black means we iterated z = z2 + c and it never escaped, so it's in the set. colors mean it escaped, and the shade tells you how fast: bright fast-escapers are far from the set, dark slow-escapers hug the edge. the detail slider is the max iterations before we give up and call a point black, and deep zooms need more of it cuz points near the edge take longer to decide. shift rotates the colors through the palette live. the corner window is the julia set for wherever your mouse is, and every point in the complex plane has its own, so you're seeing an infinite family of fractals by just moving your hand. the hud shows zoom: 1x is the whole shape, and you can go past a trillion x before the numbers run out of precision.

how it's actually built (the whole thing is tiny)

this is the entire algorithm. for one pixel, given its point (cx, cy), count the steps until it escapes:

function escape(cx, cy, maxIter){
  let x=0, y=0, i=0;
  while(x*x + y*y <= 4 && i < maxIter){
    const xt = x*x - y*y + cx;   // real part of z^2 + c
    y = 2*x*y + cy;              // imaginary part of z^2 + c
    x = xt; i++;
  }
  return i;
}

that's z = z2 + c written out with real and imaginary parts, cuz javascript has no complex number type. the escape test is x*x + y*y <= 4: once z gets further than 2 from the origin it is mathematically guaranteed to fly off to infinity, so we stop early. that one fact is why the whole thing runs in a browser at all.

why the colors are smooth and not banded

if you color by the raw integer iteration count you get ugly hard stripes. the fix is smooth coloring: after the point escapes, look at how far past 2 it overshot, and use that to add a fraction to the count. so instead of "escaped at step 37" you get "escaped at step 37.62", and that fractional part is what makes the gradients silky:

const log_zn = Math.log(x*x + y*y) / 2;
const nu = Math.log(log_zn / Math.LN2) / Math.LN2;
const smooth = i + 1 - nu;   // fractional iteration count

why it doesn't freeze your browser

rendering is split across web workers, one per cpu core. the image is cut into horizontal strips, each worker takes a strip, computes it, and hands back the pixels. the main thread just paints them as they land, so the page stays responsive even at 5000 iterations on a deep zoom. a quick low-res pass runs first so you see something instantly, then the full-res strips fill in over it. the little progress bar at the top of the image is the strips arriving.

the julia set in the corner

the mandelbrot set asks "starting at z=0, does this c escape?" a julia set flips it: fix c, and ask for every starting z whether IT escapes. so every point c on the main image has its own julia set, and they're all different. points inside the mandelbrot set give connected julia sets, points outside give dust. hover along the edge and watch them morph, it's the same six lines of code with the roles of z and c swapped.

why it eventually breaks

javascript numbers are 64-bit floats with about 16 digits of precision. zoom past roughly 1013x and neighbouring pixels stop being distinguishable, so you see blocks. that's not the fractal ending, it's the number type running out. real deep-zoom software uses arbitrary-precision arithmetic and perturbation theory to go to 10100x and beyond. that's on the try-later list.
